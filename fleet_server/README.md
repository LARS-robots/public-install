# Установка fleet-server

Получение и распаковка архива:

```bash
curl -sSL https://github.com/LARS-robots/public-install/raw/main/fleet_server/install.py | python3
```

После распаковки, перейдите в папку `fleet_server` и следуйте инструкциям в `README.md` внутри этой папки для завершения установки и запуска сервера.
